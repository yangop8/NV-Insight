## NVIDIA Open Agent Safety Platform：把 AI 智能体安全下沉入硅

【快讯内容】
NVIDIA 9/28 发布 Open Agent Safety Platform，把智能体安全下沉入硅：OpenShell（Apache 2.0 开源）在 Vera CPU 上提供内核级隔离沙箱运行时并追踪、执行策略；Sentry 在 BlueField-4 DPU 上带外监控智能体行为、越界即毫秒级隔离阻断；Anthropic、Cisco、微软、Oracle 等百余家伙伴加入。

【观点】
- **网络**：Sentry 跑在 BlueField-4 DPU 上做带外（out-of-band）监控与毫秒级隔离，把安全策略执行从主机 CPU 卸载到数据面 DPU，天然独立于被监控的智能体进程、规避“自证悖论”；契合零信任 AI 工厂东西向链路默认管控，与 09-01 追踪的 SafeMind 智能体网络安全、03-23 Zero-Trust AI Factories 一脉相承，是 DPU 作为策略执行点的又一落地。
- **系统软件**：OpenShell 以内核级隔离沙箱 + 策略追踪/执行为 agent 运行时提供可验证边界（verifiable policy），把“控制到达模型的路径、随推理可见性放大 agent 权限”固化为运行时规则；Apache 2.0 开源、可扩展到 Arm/Intel，可回灌到 vLLM/SGLang 等推理服务的进程隔离、沙箱化与运行时准入控制栈；与 09-27 追踪的机密计算生产级推理（可信执行路径）互补，属不同 URL 不同侧重（此篇为 agent 越界的运行时监控与阻断）。
- **嵌入式**：硬件根信任下的越界即隔离机制对安全关键边缘 agent 部署有方法论借鉴，但本次架构面向数据中心 Vera CPU + BlueField-4 DPU，端侧无直接产品，间接参考。
