## 一、NVIDIA 公布 Vera 存储处理器基准：加密/校验/压缩/恢复全面加速 AI 原生存储

【快讯内容】
NVIDIA 发布 Vera（BlueField-4 STX 存储处理器，88 Olympus Armv9.2 核 + SOCAMM2 LPDDR5X）存储基准：较 x86 加密/解密达 1.43×/1.29×、Reed-Solomon 恢复 3.26×、CRC32C 校验 3.67×、压缩/解压 3.29×/1.72×、多级流水线 3.21×，以更低 CPU/功耗承载 AI 原生存储服务。

【观点】
面向网络：加密/解密、CRC32C 完整性校验与压缩本是零信任数据面与东西向存储流量的关键负载，Vera 把这些算子从 x86 卸载到存储处理器近数据侧执行，对 IPsec/TLS 加密存储传输、机密计算下加密 KV/上下文搬运与存储直取拓扑的数据面卸载有直接参考价值。面向系统软件：Reed-Solomon 纠删恢复、CRC32C 校验、压缩与多级流水线代表存储栈内核级算子在专用 CPU 上的吞吐优化，对 AI 原生存储的编解码流水线调度、CPU/功耗预算与并发数据流密度有直接参考价值。面向嵌入式：Olympus Armv9.2 + Spatial Multithreading 的 SoC 级架构对边缘存储/DPU 类设备的核内多线程与能效设计有间接参考价值。

> 参考文章：[NVIDIA Vera Storage Benchmarks: Faster Encryption, Compression, Integrity Checking, and Recovery for AI-Native Storage](https://developer.nvidia.com/blog/nvidia-vera-storage-benchmarks-faster-encryption-compression-integrity-checking-and-recovery-for-ai-native-storage/)

## 二、KAI Scheduler + vCluster：在共享 GPU 基础设施上运行隔离多租户 Kubernetes

【快讯内容】
NVIDIA 技术博客演示以开源 KAI Scheduler + vCluster 在共享 GPU 上运行完全隔离的多租户 Kubernetes：各租户拥有独立控制面、RBAC、CRD 与 cluster-admin 权限，三个团队共享单块物理 GPU 且零浪费，兼得专属集群体验与调度公平。

【观点】
面向系统软件：多租户隔离、独立控制面与 GPU 共享调度直击"运行时安全（沙箱/进程隔离）"与"多节点调度"两大关注点——vCluster 提供控制面级软隔离、KAI Scheduler 负责 GPU 细粒度分时与公平队列，对 AI 工厂多租户资源编排、越权隔离与利用率-隔离权衡有直接参考价值。面向网络：租户级 RBAC 与命名空间隔离需配套租户网络微隔离/东西向策略，对多租户 AI 工厂的网络切分有间接参考价值。面向嵌入式：数据中心共享 GPU 场景，与端侧无直接参考价值。

> 参考文章：[How to Run Isolated Tenant Kubernetes Clusters on Shared GPU Infrastructure](https://developer.nvidia.com/blog/how-to-run-isolated-tenant-kubernetes-clusters-on-shared-gpu-infrastructure)

## 三、Beyond VLAs：World Action Model 以视频世界模型重塑机器人操控

【快讯内容】
NVIDIA 技术博客提出"世界动作模型"（WAM）：以视频世界模型替换 VLA 中的 VLM 语言骨干——VLM 只会描述世界而不预测其演化，WAM 则能预判场景动态变化，经后训练特化为机器人策略，开源 Cosmos 3 世界模型作为构建 WAM 的基础（Jim Fan"VLAs are dead, long live WAMs"）。

【观点】
面向嵌入式：机器人操控策略最终落到 Jetson 类端侧实时推理与安全关键控制，WAM 以世界模型预测场景演化契合需要预判动态的操控任务，对边缘机器人策略部署、端侧世界模型推理与实时闭环控制有直接参考价值。面向系统软件：视频世界模型后训练与推理是显存/上下文密集型工作负载，其 rollout 生成、KV-上下文管理与仿真-推理管线调度对推理引擎有间接参考价值。面向网络：模型架构与策略学习主题，与网络方向无直接参考价值。

> 参考文章：[Beyond VLAs: How World Action Models Reshape Robot Manipulation](https://developer.nvidia.com/blog/beyond-vlas-how-world-action-models-reshape-robot-manipulation)
