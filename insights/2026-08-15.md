## 1. FMS 2026：NVIDIA 开源 cuFile、推出 Storage-Next 与 SCADA，把存储控制放到 GPU

【快讯内容】
NVIDIA 在 FMS 2026 开源 cuFile API 及其底层垂直存储软件栈（Google/Intel/Meta 共同维护），让 GPU 以数十万线程微秒级直读存储；同时推出 Storage-Next 行业倡议（联合 DDN/Kioxia/Micron 等 40+ 厂商）与 SCADA（Scaled, Accelerated Data Access）框架把存储控制移至 GPU，并以 Vera BlueField-4 STX（Vera Rubin + BlueField-4 存储处理器 + Spectrum-X 以太网）为 AI 原生数据基础设施样板。

【观点】
- 网络：cuFile/GPUDirect Storage 让 GPU 经 DMA 从 NVMe 直取数据入显存、绕过 CPU 与主机内存，配合 BlueField-4 STX 800Gb/s + Spectrum-X 以太网，把存储数据面下沉到 DPU/网络融合层；对 AI 工厂东西向存储流量卸载、GPUDirect Storage 直取数据通路、CMX 上下文存储层与多租户存储网络隔离方向有直接参考价值。
- 系统软件：cuFile 开源 + SCADA 把存储控制放到 GPU、由数十万 GPU 线程驱动微秒级 I/O 以缓解"GPU 饿死"；对推理/训练数据加载、KV/权重冷启动加速、GPUDirect Storage 内核路径与存储软件栈自研可控性方向有直接参考价值。
- 嵌入式：面向 rack-scale 数据中心存储基础设施，无直接参考价值。
