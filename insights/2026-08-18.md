## Nemotron 3.5 Lightning NVFP4：QAD 量化蒸馏把 30B MoE 压到 22GB

【快讯内容】
NVIDIA 用 Model Optimizer 以量化感知蒸馏（QAD）为 Nemotron 3.5 Lightning（30B/3B激活 MoE）产出 NVFP4 权重：先 PTQ（专家 W4A16、mamba in/out_proj 与 KV cache FP8 动态）出学生模型，再对冻结教师用 KL 散度+模拟量化训练，几乎恢复 BF16 精度，模型 66GB→22GB、吞吐至多 4x。

【观点】
系统软件方向直接参考：QAD 把"PTQ 掉点—蒸馏回补"做成可复现管线，NVFP4 W4A16 + 选择性 FP8（对量化敏感的 mamba 投影/KV cache 留高精度）是 MoE 混合架构的精度-带宽务实切法，可直接嵌入 vLLM/SGLang/TensorRT 推理内核的低精度部署路径。嵌入式方向直接参考：22GB 显存足迹使 30B 常驻智能体下探到 DGX Spark/Jetson/RTX 单卡，NVFP4 降低访存与显存墙、提升端侧 token/s，是边缘长时智能体量化部署的关键一步。网络方向无直接参考价值。

> 参考文章：[Developing Nemotron 3.5 Lightning NVFP4 with QAD Using NVIDIA Model Optimizer](https://developer.nvidia.com/blog/developing-nemotron-3-5-lightning-nvfp4-with-qad-using-nvidia-model-optimizer/)
