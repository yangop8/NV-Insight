## 1. NeMo Gym 以「端到端产物评分」拉升芯片设计智能体可靠性与工具调用效率

【快讯内容】
NVIDIA 展示 Siemens EDA 用 NeMo Gym 优化其 Fuse EDA AI Agent 做标准单元特征化：以领域专用验证器对最终 Liberty 文件按覆盖/合法/相对校验/精度/完整性逐项评分、任一门禁不过即零奖励，据此迭代打磨 agent 的 skills 与 MCP 工具描述。GF180MCU PDK 基准综合分约 55%→95%，agent 回合 155→53、输出 token 约 81K→29K。

【观点】
系统软件：这是「harness 即可验证运行时」工程范式又一落地——把能力从模型外移到确定性的领域验证器与受限工具集，用端到端产物（而非中间步骤）评分来归因早期配置错误如何贯穿后续阶段并污染最终产物，再据诊断精修 skills/MCP 工具描述；对可审计、可复现的生产级 agent 运行时，以及用 reward/verifier 驱动工具调用治理、压缩 agent 回合与 token 成本，有直接参考（呼应 10-13 Spark UDF 重写、10-08 KDD Cup 数据智能体一脉）。嵌入式/网络：无直接参考价值。

## 2. Meta Muse Spark Open 编码大模型在 GB300 NVL72 上的智能体编码服务化

【快讯内容】
NVIDIA 解析 Meta 新开源编码模型 Muse Spark Open 在 GB300 NVL72 上的智能体编码服务：816B 总参/42B 激活 MoE，top-8 路由、256 专家，1M 上下文，另配 1.8B 感知编码器扩展音视频/图文理解。于 Blackwell Ultra 上专为智能体编码训练，放出 NVFP4 权重（BF16 约 1.65TB→NVFP4 约 537GB）压缩显存占用，厂商报告单 GPU 最高约 5 万 tokens/s、单用户约 600 tokens/s。

【观点】
系统软件：万亿级稀疏 MoE（42B/816B 激活比约 5%）生产化推理的又一范式——NVFP4 把权重压缩约 3x、配合单一多模态模型省去编码/感知双模型编排，对推理引擎的专家路由内核、KV 显存治理与量化部署有直接参考。网络：816B/256 专家的 all-to-all 专家流量高度依赖 GB300 NVL72 机架内 NVLink scale-up 域把流量留在网内、避免溢出传统以太网，印证超大 MoE 服务对 scale-up 带宽的决定性依赖，网络拓扑设计方向有间接参考。嵌入式：模型规模属机架级数据中心部署，无直接参考价值。

> 参考文章：[Scale Agentic Coding Workflows with Meta's Muse Spark Open on NVIDIA GB300 NVL72](https://developer.nvidia.com/blog/scale-agentic-coding-workflows-with-metas-muse-spark-open-on-nvidia-gb300-nvl72/)
