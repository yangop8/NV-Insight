## 1. CUDA 13.4 内存强制 GPU 共享：把 MPS 从算力分片扩展到显存边界，经 KAI Scheduler 原生调度

【快讯内容】
CUDA 13.4 为 MPS 时间片共享新增显存边界强制隔离（此前仅分算力）：可申请精确显存或"保证下限+突发上限"区间。K8s 侧开源 GPU Fractioning Operator 随 GPU Operator 配置 MPS，KAI Scheduler v0.18.0 起经 Pod 注解声明每容器显存配额与突发上限。

【观点】
系统软件方向直接参考——正中「多芯片/多节点调度」与「推理引擎内核优化」：它补齐了 GPU 细粒度共享长期缺失的一环——显存强制隔离。此前 MPS 只能分算力、显存靠"君子协定"，一个租户 OOM 可拖垮整卡；CUDA 13.4 把显存配额下沉到运行时强制执行，配合 NvFractions 的"保证下限 40Gi + 突发 60Gi"模型，使推理服务既能按 SLA 保底又能机会性复用空闲显存，直接提升单卡多模型/多租户的装箱密度与隔离安全。对自研推理栈的意义在于：GPU Fractioning Operator 以 Operator 模式自动在节点编排 MPS、KAI Scheduler 经 Pod 注解声明式下发，可直接借鉴其"算力+显存双维度分片 + 声明式 QoS"范式做小模型/Agent 服务的密集部署，与此前追踪的 Run:ai 开源（10-07·含 KAI Scheduler/GPU Fractioning Operator）、Mission Control 2.5 自主恢复（10-27·K8s 调度）形成"分片—调度—自愈"的 GPU 池化完整链路。网络方向间接参考——多租户共卡密集化加剧东西向/KV cache 跨卡流量压力，显存隔离与网络 QoS 需协同。嵌入式方向间接参考——同一"显存配额强制 + 突发区间"思路对边缘多模型共享单 GPU/Jetson 的内存隔离有借鉴，但本文面向数据中心 K8s，端侧无直接产品。（注：具体版本号/特性以 CUDA 13.4 与 KAI Scheduler v0.18.0 官方发行说明为准。）

## 2. RTX Spark 游戏端侧 AI：Nemotron 3.5 Bolt E4B 4GB 本地小模型 + RTX Kit 神经压缩，统一内存端侧栈成形

【快讯内容】
NVIDIA 公布 RTX Spark 游戏软件栈：发布 Nemotron 3.5 Bolt E4B（4GB 端侧小模型驱动游戏 AI 角色·经 IGI SDK 本地运行·输出 token 较同类少 80%）；RTX Kit 新增 8 项 RTX Spark 技术（神经纹理压缩等）；DLSS 5 神经渲染加速 2x。平台为 Blackwell+Grace+128GB 统一内存+完整 CUDA 栈。

【观点】
嵌入式软件方向直接参考——正中「边缘/端侧 AI 推理部署」与「模型量化与内存优化」：Nemotron 3.5 Bolt E4B 把一个 4GB 量级小模型做到"本地实时驱动游戏角色对话"，其"输出 token 较同类少 80%"本质是推理时延/算力预算的激进压缩，对端侧 Agent 的 KV cache 占用、功耗与响应延迟是正面信号；IGI SDK 作为端侧推理运行时抽象，与 Jetson 侧的端侧部署栈形成"消费 PC—边缘设备"两条端侧推理路线的技术互参，RTX Kit 神经纹理压缩同样是"用小模型换带宽/显存"的端侧优化范式。系统软件方向间接参考——RTX Spark 的 Grace+Blackwell 128GB 统一内存 + 完整 CUDA 栈，使端侧与数据中心共享同一编程/内存模型，本地小模型可无缝向上扩展，对跨端-云一致的推理内核（TensorRT/统一内存寻址）有借鉴。网络方向——本文面向单机端侧，无直接网络内容。消费游戏/DLSS 画质部分（NBA 2K27、Hogwarts Legacy 等）按惯例仅作背景提及，不作观点重点。（注：各项质量/速度数字出自官方博文 AI 摘要，经 daily.dev/blockchain.news 交叉核对，具体以 Nemotron 3.5 Bolt 与 RTX Kit 官方发行说明为准。）
