## 1. 用 NVIDIA RTX Spark 在单机完成编码·测试·部署（本地 AI 开发工作流）

【快讯内容】
NVIDIA 发布 RTX Spark 本地 AI 开发方案：GB10 超芯片、128GB 统一内存、1 PF FP4，让编码/测试/部署在单机完成，替代「笔记本+云 API+云 VM」三段式。提供首个 Windows on Arm 的 PyTorch-CUDA 构建、原生 Python 3.15、2000+ Conda 包、Top15000 Python 包约 97% Arm 适配；本地运行 Nemotron 3.5 Bolt（74B-A9B·2-bit·24GB，支持 llama.cpp/vLLM/Ollama/LM Studio）；可原生 Windows 或 WSL 开发，环境与云端部署一致。

【观点】
系统软件：首个 Windows-on-Arm 的 PyTorch-CUDA 构建 + 原生 Python 3.15 + Arm 原生 Conda 生态，把 CUDA 工具链完整下沉到 Arm 客户端，对 Arm 平台系统软件移植、包管理/ABI 兼容与 WSL「开发即部署」环境一致性有直接参考；GB10 128GB 统一内存让 74B-A9B 模型以 2-bit 常驻单机，对本地推理引擎（vLLM/llama.cpp）的权重/KV 显存编排与量化部署是现成范式。嵌入式：统一内存 + 低比特量化把 74B 级 MoE 压入 24GB、以客户端算力做本地常驻智能体，对 Jetson/DGX Spark 端侧推理与「主干低精度」显存预算选型有直接参考。网络：WSL 与云端环境一致主要降低部署摩擦，对网络方向无直接参考价值。

> 参考文章：[Code, Test, and Deploy on One Machine with NVIDIA RTX Spark](https://developer.nvidia.com/blog/code-test-and-deploy-on-one-machine-with-nvidia-rtx-spark/)
