# 2026-08-23 每日洞察快讯

## 安全在智能体栈中的落点：强制点下沉到"执行动作的系统"，OpenShell 内核级隔离沙箱

【快讯内容】
NVIDIA 安全团队阐述智能体栈的安全落点：栈含模型、harness、meta-harness、安全运行时（OpenShell）与推理基础设施，主张把控制置于运行时/基础设施层而非可被智能体改写的 harness 逻辑；核心为最小权限、隔离、即时授权与"智能体边界之下"的权威策略执行——每个高影响动作须跨越"由执行方系统做校验"的强制点。OpenShell 以内核级隔离沙箱运行各智能体，配声明式 YAML 策略。

【观点】
系统软件方向直接参考：把安全强制点下沉到"执行动作的系统"、置于智能体进程与可改写 harness 之外，是运行时安全（沙箱、进程隔离）的关键范式——OpenShell 内核级隔离沙箱 + 声明式 YAML 策略 + 最小权限/即时授权，确保智能体无法自我提权或绕过控制、所有高影响动作可审计，对推理运行时的隔离边界与策略引擎设计有直接借鉴。网络方向直接参考：在智能体边界之下做权威策略执行、每个高影响动作过强制点校验，本质是零信任"从不信任、始终校验"在智能体动作层的落地，对 AI 工厂多租户访问控制与东西向微分段有参考。嵌入式方向间接参考：端侧自主智能体的沙箱化与最小权限部署。

> 参考文章：[Where Security Fits in an AI Agent Stack](https://developer.nvidia.com/blog/where-security-fits-in-an-ai-agent-stack)
