## 1. AI 代理驱动 Omniverse 库构建仿真：Newton 开源物理引擎 + 机器人 sim-to-real

【快讯内容】
开发者用前沿模型代理（GPT-6、Claude Code 等）经 Omniverse 代理技能与 MCP 工具，调用一组开源 Python 库（ovstage/ovrtx 渲染、ovphysx 与 ovnewton 物理、ovxr VR、ovstream 浏览器流送、ovui）以自然语言装配 SimReady 场景、生成 pick-and-place 控制逻辑、编写 VR/what-if 应用，并对比仿真传感器输出与真实录制数据修正 OpenUSD 场景。示例覆盖 Isaac Lab 机器人（含 Unitree G1）、设施级数字孪生、仓库性能测试，底层含 Newton 引擎与 Warp。

【观点】
系统软件方向直接参考——本篇核心是「开源物理引擎（Newton，CLAUDE.md 系统软件关注点）+ 代理化仿真创作」落地：AI 代理不再只生成文本，而是经 MCP/代理技能把 ovphysx/ovnewton/ovstage 等库当可编排 API，装配场景-接物理-跑测试-读日志反馈，延续 11-21 Rust 工具调用解析器、Dynamo RL 编排的「代理驱动系统软件工程」主线；对自研仿真/工具链，提示把仿真库设计为「代理可调用的结构化技能 + MCP 接口」是降低仿真门槛的关键范式。嵌入式方向间接参考——Isaac Sim/Lab + RTX 传感器仿真 + nvblox/FoundationStereo 几何重建构成机器人 sim-to-real 上游，仿真中验证的 pick-and-place/机械臂控制策略为端侧（Jetson/IGX）部署提供先调试后落地的闭环，但本篇未涉边缘部署与量化，仅为上游仿真环节。网络方向无直接关联。
