## 一、NVIDIA 发布 Vera 存储处理基准：加密/压缩/校验/恢复大幅提速

【快讯内容】
NVIDIA 公布 Vera CPU（88 Olympus 核、176 线程、SCF 3.4 TB/s）在 BlueField-4 STX 上的 AI 原生存储处理基准：较 x86 加密 1.43x、Reed-Solomon 恢复 3.26x、CRC32C 校验 3.67x、压缩 3.29x、解压 1.72x、多级流水线 3.21x，在更低功耗/散热封套内提升存储处理与并发数据流密度。

【观点】
面向系统软件：把加密、CRC32C 校验、Reed-Solomon 纠删恢复、压缩/解压这些存储数据面例行运算从 x86 迁至 Vera CPU，对 AI 原生存储栈的数据完整性、纠删编码与压缩流水线内核优化、CPU-存储卸载调度有直接参考价值，多级流水线 3.21x 说明串联算子融合而非单点加速。面向网络：Vera 与 BlueField-4 STX 融合在硅上做安全与高带宽存储加速，加密/校验贴近数据通路可支撑机密数据面与 GPUDirect Storage 直取，对存储-网络融合卸载与在途加密链路有直接参考价值。面向嵌入式：属数据中心存储节点场景，与端侧无直接参考价值。

> 参考文章：[NVIDIA Vera Storage Benchmarks: Faster Encryption, Compression, Integrity Checking, and Recovery for AI-Native Storage](https://developer.nvidia.com/blog/nvidia-vera-storage-benchmarks-faster-encryption-compression-integrity-checking-and-recovery-for-ai-native-storage/)

## 二、在共享 GPU 基础设施上运行隔离的多租户 Kubernetes 集群

【快讯内容】
NVIDIA 演示以 KAI Scheduler + vCluster 在共享 GPU 节点上为多团队提供完全隔离的租户级 Kubernetes 集群：各租户独立控制面、RBAC、CRD 与 cluster-admin 权限，共用底层 GPU；KAI 提供拓扑感知分层 GPU 调度、按团队配额与动态分配（共享/突发队列 CRD），与 GPU Operator 集成、可扩展至数千节点。

【观点】
面向系统软件：这是多租户 GPU 云的运行时隔离范式——控制面隔离 + 每租户 RBAC/CRD/cluster-admin 提供强隔离边界，KAI 拓扑感知分层调度 + 配额/突发队列解决 GPU 细粒度共享与利用率，对多租户调度、沙箱/进程隔离、资源治理与集群级弹性有直接参考价值。面向网络：租户独立控制面天然对应网络与策略隔离边界，对多租户 AI 工厂东西向流量隔离、命名空间/租户级微分段有直接参考价值。面向嵌入式：数据中心集群编排场景，与端侧无直接参考价值。

> 参考文章：[How to Run Isolated Tenant Kubernetes Clusters on Shared GPU Infrastructure](https://developer.nvidia.com/blog/how-to-run-isolated-tenant-kubernetes-clusters-on-shared-gpu-infrastructure)

## 四、Beyond VLAs：世界-动作模型（WAM）重塑机器人操作

【快讯内容】
NVIDIA 技术博文提出以视频世界模型替换语言骨干、构成世界-动作模型（WAM）：相较在 VLM 上加动作模块的 VLA（只会描述世界、缺动力学预测），WAM 学习场景如何演变，更契合需预判的操作任务。开放的 Cosmos 3 世界模型可作 WAM 底座，经后训练特化为机器人策略（Jim Fan「VLAs are dead, long live WAM」）。

【观点】
面向嵌入式：WAM 让机器人策略具备动力学预测与跨任务泛化，直击端侧操作策略"只会模仿演示、难泛化"痛点，对机器人端侧策略部署、以世界模型做预测式控制与 sim-to-real 迁移有直接参考价值；Cosmos 3 作开放底座利于边缘微调与量化部署。面向系统软件：视频扩散世界模型作策略骨干，推理时的时序生成、显存与 KV 调度、后训练流水线（LoRA/TAO）对推理引擎与训练框架有间接参考价值。面向网络：无直接参考价值。

> 参考文章：[Beyond VLAs: How World Action Models Reshape Robot Manipulation](https://developer.nvidia.com/blog/beyond-vlas-how-world-action-models-reshape-robot-manipulation)

## 五、Alpamayo 2 Super：面向 Robotaxi/自动驾驶的前沿开放推理模型商用

【快讯内容】
NVIDIA 发布 Alpamayo 2 Super 并开放商用（OpenMDW-1.1 许可）：32B VLM 骨干（基于 Cosmos 3 Super Reasoner、经 RL 后训练）+ 2.3B 扩散式动作解码器，提供 360° 感知、高层驾驶决策与自动推理标注，面向 Robotaxi、自动卡车、配送车等移动机器人；Alpamayo 系列 Hugging Face 下载超 50 万，BYD/吉利/五十铃/日产等已采用早期版本。

【观点】
面向嵌入式：车规级自动驾驶属典型安全关键端侧推理，32B VLM + 2.3B 扩散动作解码器的推理时延、量化与车载算力（Drive/Thor 级）部署是落地关键，对端侧模型压缩、实时推理与安全认证方向有直接参考价值；开放许可（可检视/微调/部署）利于主机厂自持栈。面向系统软件：VLM 推理 + 扩散动作解码的双阶段推理管线，其显存调度与算子优化有间接参考价值。面向网络：无直接参考价值。

> 参考文章：[NVIDIA Alpamayo 2 Super, the Frontier Open Model for Robotaxis and Autonomous Vehicles, Now Available for Commercial Use](https://blogs.nvidia.com/blog/alpamayo-2-super-open-model-now-available/)
