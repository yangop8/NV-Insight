# NV-Insight 每日快讯 · 2026-10-04

## 一、DIN Deploy：C++ + TensorRT RTX 本地推理样例，ONNX Runtime EP 抽象 CPU/GPU 路径

【快讯内容】
NVIDIA 发布开源项目 DIN Deploy（Do Inference Now，GitHub NVIDIA/din-deploy）：以 C++ 样例把 ONNX Runtime 接 TensorRT RTX 执行提供器（EP），覆盖 Windows/Linux 从 checkpoint 到原生加速应用。每个样例用 Python 导出器产出 ONNX 制品、共享 C++ CLI 跑 TensorRT RTX EP 或 CPU EP，含 ASR（Whisper/Parakeet TDT/Nemotron ASR Streaming）、SAM 2.1 分割、FLUX.2-klein-4B 生图；DGX Spark 实测 Parakeet 206x 实时、SAM 2.1 GPU 38.3 FPS（CPU 0.5）。

【观点】
- **嵌入式**：直接参考价值——面向客户端 PC/DGX Spark 的本地端侧推理工程样板，把"模型 checkpoint → 原生应用"的落地门槛显著降低；ASR 流式（Nemotron 39x 实时）+ 交互式分割 + 生图三类负载均在受限设备本地完成，配套 FLUX.2-klein-4B 训练后量化（PTQ）与 Vulkan/DirectX 图形互操作，是端侧多模态推理部署与量化优化的直接范例。
- **系统软件**：直接参考价值——以 ONNX Runtime EP 作统一抽象层、把厂商相关 CUDA 代码隔离到可选加速路径、CPU EP 作回退，是"可移植推理栈 + 后端可插拔"的清晰工程分层；Python 导出器/C++ CLI 两段式分离了模型转换与运行时，对自研本地推理引擎的制品管理、EP 抽象、GPU/CPU 降级策略有直接借鉴。
- **网络**：无面向网络方向的直接参考价值——本项目聚焦单机本地推理，不涉及数据中心网络架构。
