## 1. NVIDIA 用 cuTile 为 Mamba-2 前向传播重写高性能 GPU 内核

【快讯内容】
NVIDIA 与 Jane Street 合作，用 cuTile（CUDA Tile，Python DSL 瓦片编程模型）为 Mamba-2 状态空间模型前向传播重写三个自定义内核：chunk_cumsum、fwd_pass_state（以 Tensor Core MMA 承载状态）、compute_out（融合衰减因果掩码交互项与跳连为单一瓦片内核）。配合 DRAM 延迟提示、操作数换位至 Tensor Memory、TMA 友好转置布局与按输入形状搜索块大小/占用率的自动调优器。单张 B300 SXM6 上较开源 Triton（mamba_ssm 2.3.2.post1）快 1.14~1.82x，长序列/大状态增益更显著（仅前向内核级，端到端训练还受反向传播影响）。

【观点】
系统软件：这是「用瓦片级 Python DSL 做生产级内核优化」的又一标杆——把 Mamba-2 前向的三段计算（分块累加、状态承载、输出融合）拆成可用 Tensor Core/TMA/Tensor Memory 显式编排的瓦片内核，并以自动调优器按形状搜索参数，对自研 SSM/线性注意力内核、以及 vLLM/SGLang/TensorRT-LLM 中混合 Mamba-MoE 骨干（如 Nemotron 3.5 Lightning/Super VL）的推理与训练内核有直接参考；与此前 cuTile Python→Rust 智能体化移植、CUDA Rust 双轨、C++ CUDA Tile 一脉，cuTile 正从「易写」走向「贴近手写 CUDA C++ 的峰值性能」，降低状态空间模型内核的工程门槛。嵌入式：Mamba-2 的常量显存/线性复杂度本利于长上下文端侧常驻，前向内核提速对 Jetson/RTX 边缘推理有间接参考，但本文基准在数据中心级 B300、未覆盖端侧量化，直接价值有限；网络无直接参考价值。

> 参考文章：[Accelerating Mamba-2 with High-Performance Forward Pass Kernels in NVIDIA CUDA Tile](https://developer.nvidia.com/blog/accelerating-mamba-2-with-high-performance-forward-pass-kernels-in-nvidia-cuda-tile/)
