## 1. 用 Hermes 智能体与 NVIDIA NemoClaw 部署更安全的自进化研究智能体

【快讯内容】
NVIDIA 演示以 NemoClaw 蓝图部署 Hermes 自进化研究智能体：底层跑 LangChain Deep Agents Code harness（面向 Nemotron 调优），叠加 OpenShell 开源运行时施加基于策略的安全/网络/隐私护栏。智能体从对话中直接学习复用工作流并固化为持久化 Hermes Skills（无需改代码或重启网关），并接入 Slack/Outlook 消息通道与 GitHub/开发者论坛数据（经宿主侧镜像访问），可跑在 RTX PC / DGX Spark。

【观点】
面向系统软件：核心是 OpenShell 沙箱运行时——会话隔离、动作执行前由运行时校验权限、即便智能体被攻陷也无法越权覆盖约束，配 policy.yaml 声明式列出允许的目的地/端口/HTTP 动词/可执行文件并做生命周期管理，是"智能体运行时即强制隔离边界"的工程范式，对运行时沙箱、进程隔离、最小权限与策略即代码的落地有直接参考价值。面向网络：policy.yaml 对出站目的地/端口/动词的声明式白名单本质是智能体侧的网络出口策略与零信任访问控制，对受限数据源接入、东西向/南北向流量收敛与微隔离有直接参考价值。面向嵌入式：Hermes 智能体可下沉至 RTX PC / DGX Spark 边缘设备本地运行，对端侧自治智能体的资源受限沙箱部署与本地数据隐私边界有间接参考价值。
