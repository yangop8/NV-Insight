## 1. NVIDIA TensorRT 11.1 推出 Global Performance Tuner：以精度为约束自动搜索最快 build route

【快讯内容】
TensorRT 11.1 新增 Global Performance Tuner（分两篇）：以精度为硬约束，自动搜索 200+ 可调旋钮组成的多条 build route，逐一校验精度并实测端到端性能、择最快合格引擎；10 个工作负载实测相对默认路线 1.14x~1.63x。经 trtexec 落地，支持 --dryRun 预览路线、--tuningCacheFile/--continue 可续调缓存，模型/形状/目标 GPU/软件栈变更后需重调。

【观点】
系统软件方向直接参考——正中「推理引擎内核优化（TensorRT）」：它把「单条默认 build route」升级为「精度约束下的多路线自动搜索」，解决了「单个内核在隔离下更快、但与融合/张量布局/访存流量耦合后反而更慢」的全局最优难题，把过去靠人工拧旋钮的调优变成可复现、可缓存续跑的自动流程。对自研推理服务意义在于：同一模型按目标 GPU/形状分别产出并固化最快引擎，调优结果可 --tuningCacheFile 持久化、CI 中增量续调，1.14x~1.63x 的相对收益在不改模型的前提下即可获取；与此前追踪的 Dynamo-Triton 多设备服务层集成、TensorRT 11.0 原生多设备推理形成「服务编排 + 引擎构建」两端互补。嵌入式方向间接参考——TensorRT 同样覆盖 Jetson/RTX 边缘，「目标 GPU 变更即需重调」正对应边缘「一模型多 SKU 分别构建」的工程现实，自动搜索可降低为不同 Jetson 平台找最优引擎的人工成本，但本文基准面向数据中心、未覆盖端侧量化/功耗约束，端侧直接价值待验证；网络方向无直接参考价值。
