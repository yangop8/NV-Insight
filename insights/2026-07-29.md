## 一、NVIDIA Labs 开源面向对象智能体框架 NOOA，提出六大 harness 能力

【快讯内容】
NVIDIA Labs 开源面向对象智能体框架 NOOA（智能体即单一 Python 类），提出六大 harness 能力：可编程编排循环、显式类型化对象状态、模型可调用的 harness API、长期记忆子系统等；在 SWE-bench Verified/CyberGym L1/ARC-AGI-3 上以更低 token 成本取得 SOTA。

【观点】
harness（模型外围架构）如何渲染上下文、执行动作、管理状态、判定完成，对结果的影响不亚于模型本身，与 07-08/07-09 已追踪的 Nemotron × LangChain Deep Agents「harness 即性能」范式一脉相承。面向系统软件：编排循环即普通 Python（模型可读写自身控制流）、持久化类型状态挂在智能体对象而非仅存对话历史（利于检查点/恢复/多租户调度）、上下文块与事件历史作为模型可自省管理的 API（本质是上下文窗口与 KV 生命周期管理）、长期记忆作为模型用工具自主维护的存储——直接对应智能体运行时/推理编排/状态持久化，且更低 token 成本即系统级效率，有直接参考价值。面向网络：全开放可自持栈利于本地/多云自建、规避闭源 API 出网，间接参考。面向嵌入式：边缘本地智能体部署间接。

> 参考文章：[Six Agent Harness Capabilities for Higher Model Performance](https://developer.nvidia.com/blog/six-agent-harness-capabilities-for-higher-model-performance/)

## 二、NVIDIA 在 Isaac for Healthcare 中开源首个 GPU 原生医疗物理仿真框架

【快讯内容】
NVIDIA 在 Isaac for Healthcare 中开源首个 GPU 原生医疗物理仿真框架（含腔内与外科手术模块），基于 Warp/Newton Physics/CUDA 做实时高保真器械—解剖交互与统一物理-成像管线，8192 个并行仿真环境把手术机器人策略训练从 5 小时压至 2 分钟内。

【观点】
框架直面医疗机器人数据稀缺、泛化难、原型迭代慢三大痛点，CMR Surgical/强生 MedTech/美敦力/XCath/Inner Logic 已用于手术数字孪生、血管介入策略训练与合成监管数据。面向系统软件：底座是开源物理引擎 Newton + Warp + CUDA 的 GPU 原生大规模并行仿真（8192 环境），统一物理-成像流水线，sim-to-real 策略训练的确定性调度与 GPU 利用率优化——Newton 正属本项目明确关注的系统软件方向，有直接参考价值。面向嵌入式：外科/介入机器人属安全关键端侧系统，训练出的策略需在 Jetson 级边缘实时低时延推理并满足安全认证，直接参考。面向网络：无直接参考价值。

> 参考文章：[Developing Healthcare Robotics with GPU-Native Medical Physics Simulation](https://developer.nvidia.com/blog/developing-healthcare-robotics-with-gpu-native-medical-physics-simulation)（blogs 侧上市公告 companion：[NVIDIA Open Sources First GPU-Accelerated Medical Physics Simulation Framework](https://blogs.nvidia.com/blog/medical-physics-simulation-open-source/)，同主题不同 URL，归入此条）

## 三、NVIDIA Ising Calibration 1.5 实现量子处理器全自动校准

【快讯内容】
NVIDIA 发布 Ising Calibration 1.5——用视觉语言模型解读量子处理器诊断输出并决定如何调校，凭零样本与在场景内（in-context）学习分析未见过的诊断结果，经 QCalEval 基准验证 SOTA，把 QPU 校准从数天缩短至数小时，支撑 AI 智能体全自动持续校准。

【观点】
模型在多种量子比特模态数据集上训练，可利用相关实验示例做在场景内推断。面向系统软件：以 AI 智能体驱动硬件持续校准/自动 bring-up 属运行时自动化运维范式，且 VLM 需在推理侧做零样本/在场景内的低时延服务部署，与此前 07-16 日本生态篇提及的 NVQLink 量子-经典混合实时控制方向呼应，有间接参考价值。面向网络与嵌入式：本篇聚焦量子计算校准，与数据中心网络架构、端侧 AI 推理部署无直接参考价值。

> 参考文章：[NVIDIA Ising Enables Fully Automated Quantum Computer Calibration with Enhanced In-Context Learning](https://developer.nvidia.com/blog/nvidia-ising-enables-fully-automated-quantum-computer-calibration-with-enhanced-in-context-learning)
