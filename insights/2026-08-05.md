## ① 共享 GPU 上的隔离多租户 Kubernetes 集群

【快讯内容】
NVIDIA 发布在共享 GPU 基础设施上运行隔离多租户 Kubernetes 集群方案：KAI Scheduler 做拓扑感知分层 GPU 调度与按团队配额/突发（自定义队列 CRD、集成 GPU Operator、可跨数千节点），vCluster 为每团队虚拟化独立控制面（独立 API Server/CRD/RBAC），底层共享同一 GPU 节点，无共享控制面节点、无租户间横向路径。

【观点】
面向系统软件多租户 GPU 调度、控制面/租户运行时隔离、配额与突发弹性、共享硬件利用率最大化方向有直接参考价值；网络层「租户间无横向路径」即微隔离/零信任东西向边界间接相关；嵌入式无直接参考价值。

> 参考文章：[How to Run Isolated Tenant Kubernetes Clusters on Shared GPU Infrastructure](https://developer.nvidia.com/blog/how-to-run-isolated-tenant-kubernetes-clusters-on-shared-gpu-infrastructure)

## ② Vera BlueField-4 STX 存储处理器基准

【快讯内容】
NVIDIA 公布 Vera BlueField-4 STX 存储处理器基准：88 核 Olympus Armv9.2 + 空间多线程 + 可扩展一致性结构 + SOCAMM2 LPDDR5X，较 x86 在加/解密 1.43x/1.29x、Reed-Solomon 恢复 3.26x、CRC32C 校验 3.67x、压缩 3.29x/解压 1.72x、多级流水 3.21x，为 AI 原生存储以更低 CPU/功耗完成企业级数据服务并压降容量与带宽需求。

【观点】
面向系统软件存储数据面卸载、加密/完整性校验/压缩流水与运行时安全组件、DPU 近数据处理方向有直接参考价值；网络存储侧以 DPU 卸载降低东西向搬运与主机 CPU 开销直接相关；嵌入式 Arm+LPDDR5X 每瓦性能路线间接。

> 参考文章：[NVIDIA Vera Storage Benchmarks: Faster Encryption, Compression, Integrity Checking, and Recovery for AI-Native Storage](https://developer.nvidia.com/blog/nvidia-vera-storage-benchmarks-faster-encryption-compression-integrity-checking-and-recovery-for-ai-native-storage/)

## ③ 从 VLA 到世界动作模型（WAM）

【快讯内容】
NVIDIA 提出以视频世界模型替换语言主干构建「世界动作模型」(WAM)：VLA 的 VLM 主干只会描述世界、不预测其演化，缺失机器人所需的动力学（抓取闭合、毛巾折叠、物体落点）；WAM 以视频世界模型打底赋予物理推理，经后训练特化为机器人策略，Cosmos 3 世界模型提供基础，改善超出示范数据的泛化。

【观点】
面向嵌入式机器人操作策略端侧部署、Cosmos 3 世界模型量化与实时推理、Jetson Thor 级安全关键低时延推理方向有直接参考价值；系统软件世界模型预训练/后训练管线与仿真数据调度间接；网络无直接参考价值。

> 参考文章：[Beyond VLAs: How World Action Models Reshape Robot Manipulation](https://developer.nvidia.com/blog/beyond-vlas-how-world-action-models-reshape-robot-manipulation)

## ④ FMS 2026：开源 cuFile 与垂直存储栈

【快讯内容】
FMS 2026（8/4-6，圣克拉拉）NVIDIA 宣布开源 cuFile API 及其下垂直存储软件栈：作为 GPUDirect Storage 组件，让 GPU（而非仅 CPU）用数十万线程与高带宽显存微秒级安全直读写存储，构建基于 Linux 最佳实践、安全优先、GPU-数据互操作的统一存储栈。

【观点】
面向网络存储数据面（GPUDirect Storage / RDMA 直取、绕过 CPU 降低搬运时延与东西向冗余）、系统软件安全优先存储栈与 GPU 直连 I/O、KV/上下文自存储层直取方向有直接参考价值；嵌入式无直接参考价值。

> 参考文章：[As AI Increases Demands on Memory, Storage Steps Up](https://blogs.nvidia.com/blog/ai-storage-fms/)
