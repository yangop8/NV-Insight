【快讯内容】
NVIDIA 发布 ModelExpress（MX）：以多线程流式、原子化分布式缓存、GPUDirect Storage 直通与运行时传输路径自选，把数百 GB~TB 级模型 checkpoint/权重在集群内近线速分发，消除冷启动瓶颈与冗余数据搬运。

【观点】
面向**系统软件**方向有直接参考价值：MX 把"权重加载"从推理冷启动关键路径中剥离——GPUDirect Storage 绕过 CPU/页缓存让 NVMe/存储直灌显存，原子化分布式缓存避免同一权重在多节点重复拉取，运行时按拓扑自选传输路径（本地 NVMe / 节点间 RDMA / 对象存储），对大模型/MoE 弹性扩缩容与故障快恢的 TTFT 尾时延是硬指标级优化，可与既有推理栈（Dynamo/分离式服务）的 KV/权重编排协同。面向**网络**方向亦有直接价值：跨节点权重分发本质是东西向大流量搬运，"最小化冗余传输 + 缓存命中"直接降低 scale-out fabric（Spectrum-X/Quantum-X）拥塞与占用；对**嵌入式软件**边缘多机部署的模型下发有间接借鉴。

> 参考文章：[ModelExpress: Distributing Model Artifacts at the Speed of Light](https://developer.nvidia.com/blog/modelexpress-distributing-model-artifacts-at-the-speed-of-light)

【快讯内容】
Nemotron 3 Ultra 在 CVDP 智能体 RTL 编码基准以 ACE-RTL harness 取得九类任务平均 97.1% 通过率，超过 GLM 5.2/Kimi K2.6 且每轮迭代少用至多 71% token；采混合 Mamba-Attention 架构、1M 上下文，Mamba-2 层对序列长度线性复杂度。

【观点】
面向**系统软件**方向有直接参考价值：其一，混合 Mamba-Transformer/Attention 的线性时间层是长上下文智能体循环的关键系统级优化——迭代式 RTL 设计-验证需反复读回长设计上下文，线性复杂度直接压低 KV 显存与注意力算力墙；其二，"少用 71% token 达同/更高准确率"是推理经济学的实打实收益，token 即算力即成本，对推理引擎的批调度、KV 复用与每瓦吞吐是可量化杠杆。RTL/芯片设计属垂直域，但"harness 即性能"（围绕模型工程化工具调用与上下文管理）与前几日 LangChain Deep Agents 主线一脉相承。面向**嵌入式软件**方向间接（EDA 侧非端侧部署），**网络**方向无直接。

> 参考文章：[NVIDIA Nemotron 3 Ultra Leads Open Models on Accuracy and Efficiency in Agentic RTL Coding](https://developer.nvidia.com/blog/nvidia-nemotron-3-ultra-leads-open-models-on-accuracy-and-efficiency-in-agentic-rtl-coding/)

【快讯内容】
NVIDIA 扩展 Agent Toolkit，将重构的 PhysicsNeMo 与更新的 CUDA-X 库封装为智能体可调用工具/技能，新增 cuISS（CUDA 迭代稀疏求解器）加速大规模稀疏线性系统的物理/工程仿真；Cadence/Siemens/Synopsys 等采用推进自主工程工作流。

【观点】
面向**系统软件**方向有直接参考价值：cuISS 以模块化可组合的求解器 + 预条件子在 GPU 上求解大稀疏线性系统，是 CFD/结构/电磁等仿真内核的底层加速原语，与 CUDA-X（cuDSS/cuSPARSE 谱系）共同把"物理求解"纳入 GPU 加速库栈；PhysicsNeMo 把 AI 物理模型架构"变为可调用工具"，本质是让智能体编排调度异构算子（数值求解 + 神经代理模型）的系统级集成范式。面向**嵌入式软件**方向间接（仿真-验证在云/工作站侧、非端侧），**网络**方向无直接。属 NVIDIA Newsroom 公告，暂未见对应 blog 长文，按具体可溯源 URL 登记成篇。
